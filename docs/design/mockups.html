1 · Design language

One page that shows them all

Every surface draws from the same eleven colour tokens, four fonts and four sizes that packages/ui already has. Nothing new is a token: tints, hovers and raised surfaces are mixed from the tokens, so an event's theme (or the light scheme) restyles every page at once. Try the switch at the top right.

Eleven tokens, one job each

Primary is for the one thing to do (and links and focus). Accent marks highlights only: the avatar, a featured item. Status colours mean status and nothing else: the "now" line is primary, not red. A colour used as text, and the text on a fill, are computed: see the next block.

Computed per theme, not tokens

A colour used as text or line, and text on a colour

The eleven tokens promise very little about contrast, so packages/ui computes four kinds of value when a theme is published. Ink: a colour used as text, icon or meaningful line (links, the current tab, the now line, the focus ring) is darkened on a light scheme, or lightened on a dark one, until it reaches 4.5:1 on surface and background. Muted text gets the same treatment. Field borders reach 3:1. On: text on a fill is the theme's text or background, whichever reads at 4.5:1, else black or white; primary_text is kept when it reads. Every one of these is checked against every ground it can sit on, not only the page and the card: tints, the hero panel, the poster glow, a selected row. A value that already reads is left alone. The Studio runs the same check before Publish. The first pair of tables is for the theme in the switch.

14 · Cues: picture and sound

When something happens, the screen shows it and, if you want, sounds it

A cue is a visual effect plus an optional sound; either half can play alone. Beside the effects inside a box (sheet 11), a cue can move the whole box. A cue is subtle but not brief: after a small move, a frame, a glow or a tint holds for one to two minutes and fades slowly. Under it all the stage has a heartbeat: a slow pulse of light with no sound, whose rate follows how busy the event is.

15 · Two backgrounds

The stage sets the mood; each card carries its own art

A screen has two kinds of background. The stage is the whole screen behind the boxes: it belongs to the scene and never stands still. Any box can ask the stage for a tint for a while, which is how a surging game takes over the room's colour for a minute.
